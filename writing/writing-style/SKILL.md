# Writing Style

Apply this skill to every writing task. It owns topic architecture, continuity, voice, paragraph craft, evidence discipline, and the final prose audit. It does not own category templates, frontmatter, file placement, or publishing.

Read and apply [the prose system](references/prose-system.md) before drafting or revising.

## Workflow

1. Identify the audience, purpose, governing question, factual claims, and intended decision or takeaway.
2. Build the article spine before polishing sentences. Write one sentence that states the piece's controlling question, then arrange the minimum topic blocks in dependency order. Each block must inherit an object or question from the previous one and produce what the next block needs.
3. Test the outline alone. Headings should reveal a coherent route through the subject, keep siblings at the same level of abstraction, and separate the main mechanism from optional branches, applications, and history.
4. Preserve the author's meaning, technical confidence, and point of view. Preserve facts, citations, links, names, numbers, code, equations, frontmatter, tables, and asset paths unless the task explicitly changes them.
5. Draft or revise at paragraph level. Give each paragraph an entry, development, and landing. Connect its first sentence to the prior paragraph; make the middle do the explanatory work; make the final sentence state the result, consequence, or question that hands off to what follows.
6. Separate source-reported evidence from synthesis and judgment. Research missing facts from canonical or first-party sources when the task authorizes research. Never strengthen prose by inventing facts, citations, measurements, or motivations.
7. Prefer connected prose when ideas depend on one another. Use bullets only for parallel, independently scannable facts, options, checks, or artifacts.
8. Add a table, equation, diagram, or figure only when it answers a question more clearly than prose. Introduce what the reader should notice and interpret the object afterward.
9. Run the silent structure, continuity, and prose audits in `references/prose-system.md` before delivery.

## Boundaries

- Follow the matching category skill for format and repo mechanics; category rules override this base only where the reading task genuinely differs.
- Do not make every category sound alike. The shared voice should survive different reading modes and levels of depth.
- Do not imitate another writer's persona, anecdotes, signature phrases, or sentence patterns. Borrow durable editorial mechanics only.
- Keep file diffs reviewable. Do not rewrite unrelated passages during a scoped edit.
- When returning prose directly, lead with the revised text and briefly state material editorial choices only when useful.
