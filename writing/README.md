# Writing skills

Always begin with [`writing-style`](writing-style/SKILL.md), then load one primary template when the task has a category.

An explicit site category wins. When the category is unstated, choose by the reader's primary job: Blog advances a thesis, teaches a mental model, or synthesizes evidence; Revision Notes preserve a source for retrieval; Paper Notes reconstruct one paper for later decisions.

| Task | Template |
| --- | --- |
| Single research paper | [`write-paper-note`](write-paper-note/SKILL.md) |
| Essay, intuition-first explainer, or multi-paper survey | [`write-blog-post`](write-blog-post/SKILL.md) |
| Lecture, course, book, or source notes | [`write-revision-notes`](write-revision-notes/SKILL.md) |
| Coding interview practice problem | [`write-code-practice-problem`](write-code-practice-problem/SKILL.md) |

Use [`publish-website-writing`](publish-website-writing/SKILL.md) only when writing must be routed, validated, and shipped on `arunabh1904.github.io`.
